## ‼️ Attention: Final release supporting macOS 14

**This is the last Themerr release supporting macOS 14 (Sonoma).** Future releases will require a newer version of macOS.

## ✨ Highlights

- **Built-in MCP server.** Connect MCP-compatible clients to Themerr, with access token management directly in the web UI. ([#631](https://github.com/LizardByte/Themerr/pull/631))
- **More reliable Plex and Jellyfin dashboards.** Fix duplicate items and preserve items shared across multiple libraries, keeping counts and upload progress accurate. ([#627](https://github.com/LizardByte/Themerr/pull/627))
- **Complete Jellyfin library browsing.** Movies remain visible when Jellyfin groups them into collections. ([#639](https://github.com/LizardByte/Themerr/pull/639))
- **Improved startup reliability.** Fix configuration parsing errors that could prevent Themerr from starting. ([#630](https://github.com/LizardByte/Themerr/pull/630))
- **Reduced Docker disk activity.** Avoid repeatedly extracting the application bundle during startup and health checks, reducing unnecessary disk writes. ([#660](https://github.com/LizardByte/Themerr/pull/660))

For a comprehensive list of changes, see below.
