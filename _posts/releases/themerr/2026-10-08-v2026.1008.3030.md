## ‼️ Attention: Themerr now supports Plex and Jellyfin!

Themerr-plex has been renamed to **Themerr**! Manage Plex and Jellyfin servers from the same standalone application, with shared library browsing, theme playback, and processing history. This release also provides a migration path from the older Themerr-jellyfin plugin. ([#600](https://github.com/LizardByte/Themerr/pull/600))

## ⚠️ Breaking changes and migration notes

- **Update launchers and Docker references.** Release archives now use the Themerr name. Launch `themerr`, or `themerr.app` on macOS, and update Docker deployments to `lizardbyte/themerr`. Preserve your existing configuration directory or `/config` volume to retain saved settings, server connections, and history.
- **Keep your existing credential encryption key.** Docker and headless installations use `THEMERR_TOKEN_KEY_FILE`. The previous `THEMERR_PLEX_TOKEN_KEY_FILE` name remains supported; use the same key file when changing the variable name. This key also protects saved YouTube cookies.
- **Review Jellyfin migration settings before connecting.** Connect through **Servers > Jellyfin** using a Jellyfin API key. By default, Themerr recognizes unchanged themes from the older Themerr-jellyfin plugin and removes that plugin and its repository after connecting. These preferences are available under **Settings > Jellyfin**.
- **Make Themerr reachable from Jellyfin.** Save a Themerr address on the connected server card so Jellyfin can install its connector. With Themerr's default self-signed certificate, use the connector repository on HTTP port `9495` and publish that port in Docker. Use an address reachable from the Jellyfin server; `localhost` inside another container refers to that container.
- **Older Plex plugin installations still require migration.** If upgrading from `v2024.813.13709` or earlier, follow the [standalone application migration notes](https://github.com/LizardByte/Themerr/releases/tag/v2026.1004.152244) before starting this release.

## ✨ Highlights

- **Jellyfin integration.** Add themes to movies, series, and collections on Jellyfin 10.11.x and stable Jellyfin 12.x starting at 12.1, including 12.2. Existing user themes are protected by default, with optional replacement and backups. ([#600](https://github.com/LizardByte/Themerr/pull/600), [#613](https://github.com/LizardByte/Themerr/pull/613))
- **Automatic Jellyfin connector management.** Themerr installs and updates the matching connector, waits for playback to finish before automatic restarts, and fixes connector replacement restart loops. ([#600](https://github.com/LizardByte/Themerr/pull/600), [#606](https://github.com/LizardByte/Themerr/pull/606))
- **Remote Plex cleanup over SSH.** Remove older uploaded themes, posters, and artwork through SFTP when Plex runs on another machine. Configure password or private-key authentication with server fingerprint verification directly from the updated server cards. ([#619](https://github.com/LizardByte/Themerr/pull/619))
- **Safer YouTube cookie storage.** Saved cookies are encrypted and masked in Settings, with explicit controls to reveal, replace, or clear them. Existing saved cookies are encrypted automatically when upgrading. ([#612](https://github.com/LizardByte/Themerr/pull/612))
- **Accurate ThemerrDB deployment status.** The deployment indicator now reads the timestamp from ThemerrDB's published metadata. ([#615](https://github.com/LizardByte/Themerr/pull/615))
- **Updated Docker packaging.** Docker images now use an Alpine runtime with the packaged Themerr application and bundled Jellyfin connectors. ([#625](https://github.com/LizardByte/Themerr/pull/625))

For a comprehensive list of changes, see below.
