## ‼️ Attention

This release contains a high-severity security update for Linux hosts. For more information, see:

- [GHSA-fp6g-27w5-489j](https://github.com/LizardByte/Sunshine/security/advisories/GHSA-fp6g-27w5-489j)

Linux users should update as soon as possible!

## ⚠️ Breaking changes and migration notes

- Windows hosts using Virtual HID Driver must update to version `2026.914.1218.10` or newer. Earlier driver versions are not supported by this Sunshine release.

## ✨ Highlights

- **Clearer Windows virtual-input choices.** A new `gamepad_driver` setting lets users choose all available drivers, only Virtual HID Driver, or only ViGEmBus. Selecting ViGEmBus also suppresses Virtual HID Driver notifications. ([#5653](https://github.com/LizardByte/Sunshine/pull/5653))
- **More reliable Linux capture and encoding.** This release fixes multi-plane DMA-BUF handling for wlroots capture, corrects variable-rate behavior across KWin versions, and allows Portal capture with VA-API to use high-priority EGL contexts. ([#5699](https://github.com/LizardByte/Sunshine/pull/5699), [#5705](https://github.com/LizardByte/Sunshine/pull/5705), [#5709](https://github.com/LizardByte/Sunshine/pull/5709))
- **Improved encoder compatibility.** Updated to FFmpeg 9. Fixes include accurate AV1 and HEVC capability detection, FFmpeg 9 Vulkan queue support, NVENC support in Linux builds without CUDA, and ARM64 NVENC DLL loading on NVIDIA RTX Spark. ([#5554](https://github.com/LizardByte/Sunshine/pull/5554), [#5675](https://github.com/LizardByte/Sunshine/pull/5675), [#5698](https://github.com/LizardByte/Sunshine/pull/5698), [#5682](https://github.com/LizardByte/Sunshine/pull/5682))
- **Correct network-interface binding.** Sunshine now consistently respects the configured `bind_address`, including IPv4 addresses in dual-stack mode, and Web UI links use the configured address correctly. ([#5700](https://github.com/LizardByte/Sunshine/pull/5700))
- **Easier XDG Portal recovery.** Linux and FreeBSD users can clear a stale Portal restore token directly from the Troubleshooting page and select their display again. ([#5701](https://github.com/LizardByte/Sunshine/pull/5701))
- **Broader Linux availability.** Release coverage now includes Alpine Linux 3.24 packages, openSUSE Leap 16.0 and Tumbleweed builds, and Ubuntu 26.10 packages.

For a comprehensive list of changes, see below.
