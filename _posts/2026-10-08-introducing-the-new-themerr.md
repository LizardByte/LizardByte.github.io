LizardByte now maintains one unified [Themerr](https://github.com/LizardByte/Themerr)! We recently revived
Themerr-plex as a standalone application, then added Jellyfin support and renamed it Themerr. With both platforms
supported in one application, [Themerr-jellyfin](https://github.com/LizardByte/Themerr-jellyfin) has been archived.

## What is Themerr?

Themerr adds theme songs to your movies, collections, and TV shows in Plex and Jellyfin servers using
[ThemerrDB](https://app.lizardbyte.dev/ThemerrDB/), a community-maintained database of theme songs.

## What's new?

The unified application provides several benefits over the previous plugin versions:

- Manage multiple Plex and Jellyfin servers from one instance, with server discovery and OAuth login for Plex.
  Choose which libraries to process on each server.
- Add themes to collections on both platforms, including new collection support for Jellyfin.
- Match Jellyfin TV shows using TheTVDB metadata as well as TMDB.
- Get a clearer view of theme coverage in your libraries and better error reporting, with searchable logs.
- Contribute themes to ThemerrDB more easily.
- Preview theme songs directly in Themerr.

Migrate to the new Themerr today! Visit the [documentation](https://docs.lizardbyte.dev/projects/themerr/latest/)
for installation and setup instructions, or [browse the releases](https://github.com/LizardByte/Themerr/releases)
to download the application.
